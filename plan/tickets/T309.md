## Do
- Server: an `EventHub` sink forwarding job-completion / backup-failed events to a configurable ntfy base URL + topic (setting + env; off when unset); never blocks the event path; retry with bounded backoff; no secret in logs.
- Deploy: ntfy Deployment/Service/(Ingress) templates with auth-required default, values for base URL/topic, Secret for token.
- Android: UnifiedPush receiver (UnifiedPush connector library: record the dependency in HANDOFF; works with the ntfy app as distributor); registers an endpoint via the server/ntfy topic setting; incoming message -> post a Server-events notification (channel from T308).
