# F-18 — Web Dictionary page: examples failure must not hide the entry
- Phase: P4 (human-reported) · Model: haiku · Risk: low · Deps: none
- Owned paths: `web/src/routes/dictionary/`, `web/src/lib/dictionary/`
## Problem
On the Dictionary page, when the examples request fails (501, error, or empty), the entry that loaded fine is hidden.
## Fix
Load the entry and the examples independently; an examples failure or empty result simply omits the examples section (no error banner replacing the entry). Strings via i18n.
## Acceptance
- `make check MODULE=web` green. (UI: no test required; a small vitest for the load logic is welcome if it's separable.)
