## Do
Minimal Android app that declares AnkiDroid's ContentProvider authority (`com.ichi2.anki.flashcards`) and permission (`com.ichi2.anki.permission.READ_WRITE_DATABASE`), implements decks / models / model fields / notes insert / duplicate query against an in-memory store, and logs every call with arguments to a screen and logcat. Two build variants: own applicationId and `com.ichi2.anki` (default install per single-session mode). Base the provider URIs/columns on AnkiDroid's public `FlashCardsContract` (api module).
