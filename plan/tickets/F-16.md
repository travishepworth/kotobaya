# F-16 — /api/v1/health reports build version
- Phase: P4 (hotfix, minor) · Model: sonnet · Risk: low · Deps: none · Batched with F-15
- Owned paths: health handler file in `server/src/main/kotlin/kotobaya/server/` (App.kt has hardcoded "0.1.0"), `server/build.gradle.kts` (version resource generation only), server test for health.

## Problem
/api/v1/health returns hardcoded "version":"0.1.0" under 0.1.1.

## Fix
Derive the version from the build version (the same version the image/tag build uses; e.g. Gradle `project.version` written into a generated resource, or the jar manifest Implementation-Version). Fallback "dev" when absent.

## Acceptance
- Test asserts health version equals the build-provided version (not a literal).
