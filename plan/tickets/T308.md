## Do
- Channels: Due count (min importance, silent, no status-bar icon, text '142 due · 38 new', permanent), Nudges (default; alert past a due threshold or an evening reminder if no review today; OFF by default; settings), Server events (low).
- `NextAlarmCalculator` (pure): given sorted card due instants, now, time zone, last alarm and the 15-minute batching rule, returns the next inexact alarm time (or none). Inexact alarm (`setAndAllowWhileIdle`/`setWindow`), no exact-alarm permission. Reschedule after each review, each sync, app open, boot, `TIME_SET`, `TIMEZONE_CHANGED`.
- `DueTrigger` fan-out: a small listener interface (`onDueChanged`) the widget (T307) and the notification both subscribe to via Koin; the alarm receiver calls it.
- Permission onboarding for POST_NOTIFICATIONS (Android 13+) with a rationale screen; graceful degrade when denied.
- 'Sync stale 2 days' server-event notification from `SyncStatusRepository`, posted at most once per stale episode.
- Koin module + registration line in `di/FeatureModules.kt` (flag in HANDOFF).
