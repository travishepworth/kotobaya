## Do
- `coverage/aggregate.py` (pure): tokens per segment → occurrences (count per seq, `pos_class` = most frequent class, tie per C-12), `sentence_ids` (first 20 by ordinal), `token_count`, `unmapped_token_count`, deck-item records (position by in-deck frequency, tie by seq; occurrence_count summed over segments), `JobResultMedia` numbers.
- `media/pipeline/import_job.py`: handler for `media-import`: fetch blobs, detect format, extract (T402), append after existing segments when `media_id` is an existing media, parse (T403b with media-scoped overrides), cut audio clips when `options.cut_audio` (T409) and set `sentence.audio_blob_hash`, aggregate, publish via T404a. URL and paste sources too.
- `media/pipeline/parse_job.py`: handler for `media-parse`: re-parse the media's existing sentences (text from `app.sentence`, keep ids via T404a), re-aggregate, publish a new content version. `source = jpdb` never reaches here (API returns 409).
- Progress per segment; cancellation between segments; failures leave the previous content version intact (publishing is the last step).
- Handlers are factories; registration in `build_registry` is W-5.
