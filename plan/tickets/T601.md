## Do
- Server: `synthesizeSpeech` handler enqueues job kind `tts` with payload `TtsRequest`, dedupe key
  `tts:<sha256(voice + NUL + text)>`; existing queued/running job -> 200, else 202. Voice default = setting
  `tts.voice`, else server default. Emits no ops (changes no note).
- Worker `tts` handler: call VOICEVOX (`/audio_query` then `/synthesis`), convert WAV -> mono Opus/Ogg with ffmpeg
  (reuse `audio/clips.py` conventions), store as blob kind `audio`, origin `tts`; result `JobResultTts`.
- Cache: before calling VOICEVOX, reuse the result of an earlier succeeded `tts` job with the same dedupe key
  whose blob still exists (no new table).
- Helm: `voicevox` Deployment + Service (CPU image, pinned tag, non-root, read-only root fs where the image allows;
  else document why), `voicevox.enabled` toggle; network policy lets only the worker reach it.
- Register `tts` in the worker registry.
