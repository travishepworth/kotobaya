## Read
- Spec: Content and media import › Own-file import (Subtitles: "optional audio clips cut from a video or audio file you upload"); Architecture (object storage addressed by content hash)
- Contracts: contracts/api/openapi.yaml `MediaImportFile` (`audio_blob_hash`), `MediaImportRequest.options.cut_audio`; contracts/db/V1__init.sql `app.blob` (`kind = audio`, `origin = clip`; row inserted after the object is durable), `app.sentence.audio_blob_hash`
- Code seams: `worker/src/kotobaya_worker/dict/package/s3.py` (`S3Client`), `importers/jpdb_history/apply.py` `make_fetch_blob`

## Do
- `cut_clips(source_bytes|path, sentences, opts) -> dict[sentence_index, blob_hash]`: one ffmpeg subprocess call per clip (or a segment-muxer batch), audio only, Opus in Ogg (or AAC/M4A if the Android player needs it — choose one, state why in HANDOFF), mono, ~48 kbps, small padding (default 150 ms each side, clamped to the source), deterministic encoder flags so identical input → identical bytes where ffmpeg allows (hash stability is best-effort; storage is by whatever hash results).
- Store each clip by SHA-256 via S3 + `app.blob` insert (existing hash = no-op); return the hashes for T404b to put on `sentence.audio_blob_hash`.
- Source is fetched by hash to a temp file (large videos: stream to disk, never fully into memory); temp files always cleaned up; ffmpeg errors reported per clip without failing the whole batch (failed clips listed).
- ffmpeg is invoked via `subprocess` (no Python dependency). The worker image gets ffmpeg in W-5.

## Acceptance (each bullet → at least one named test)
- [ ] With ffmpeg available: a generated test tone (`ffmpeg -f lavfi`) cut by `sample.srt` timings yields one clip per cue whose duration ≈ cue length + padding (± 50 ms, via ffprobe); clips stored once per hash.
- [ ] Without ffmpeg on PATH: those tests skip with a clear reason; pure tests (padding/clamping math, command construction, cleanup on error) always run.
- [ ] `make check MODULE=worker` green.
- Human checks: cut clips from one real episode and listen to five.

## Out of scope
