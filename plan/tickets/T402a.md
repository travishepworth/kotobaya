## Do
- `extract/model.py`: frozen dataclasses `ExtractedSegment(kind, title, sentences)` and `ExtractedSentence(text, start_ms|None, end_ms|None, location|None, reading_hints)`; `reading_hints` = list of (UTF-16 start, end, reading) for ruby/furigana (used by T402b, empty here). An `Extractor` protocol: `(bytes, filename, options) -> list[ExtractedSegment]`; a `detect_format(filename, declared)` for `format: auto`.
- `extract/split.py`: Japanese sentence splitter (。！？!?… and closing brackets「」『』（）, newline handling per source); never yields empty text; keeps original characters (normalisation is the parser's job).
- `subs/`: SRT, ASS (Dialogue lines, strip `{\...}` override tags, `\N` line breaks, ignore Comment lines, sound-effect cues kept as text), VTT (cue settings, `<c>`/`<ruby>` tags stripped). One sentence per cue (multi-line cues joined; split only when a cue clearly holds two sentences — document the rule); timestamps in ms.
- `text/`: TXT (encoding sniff utf-8/utf-8-sig/shift_jis/euc-jp; blank-line paragraphs; optional chapter headings `第N章`/`Chapter N` as segments when the file has them, else one `whole` segment) and text-hooker logs (one line per hooked line, dedupe consecutive repeats, strip timestamps if present).
- New self-written CC0 fixtures: `sample.ass`, `sample.vtt`, `sample.txt` (Shift-JIS variant too), `sample-texthooker.txt`, each with a `.expected.json` of segments/sentences.
