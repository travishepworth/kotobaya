## Do
A thin Python 3.12 CLI package in `cli/` (uv project, entry point `kotobaya`) built on the generated
Python client in `clients/python/` (path dependency). No new third-party deps beyond what the
generated client already uses plus stdlib `argparse` (or document one in HANDOFF.md).
- Config: `--server` / `KOTOBAYA_URL`, token from `KOTOBAYA_TOKEN` (a PAT); never print the token.
- Commands (minimum): `kotobaya health`, `kotobaya cards find '<query>' [--json] [--limit N]`,
  `kotobaya media import <file> [--deck NAME] [--title T]` (blob upload + media import via the API
  operations the client exposes), `kotobaya jobs list [--json]`, `kotobaya jobs watch <id>` (poll).
- Human output: compact tables; `--json` prints the raw API JSON.
- Errors: non-zero exit and a one-line message on HTTP errors (401 → "token missing or revoked").
