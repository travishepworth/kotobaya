## Do
- `RejectedOpsService` (pure logic over `DeviceStore`): list rejected rows (what, when, why, code, grouped under window parent), actions: **Retry** (-> pending), **Discard** (delete + set `rebuild_pending`, rebuild via T303b, clock repair when a discarded row was `clock_ahead`), **Re-mint** per §10.4 exactly, in ONE transaction: selection pass (1a/1b/1c, lists W/C/D/E/R/U, E order), reviews re-minted with corrected `reviewed_at` and new ids, window rows re-minted with the same row ids at `mint_at(estimated real time)`, window-derived ops (`deck.item_put/_removed` `e:<seq>` re-key rules incl. live-owner condition and double removal, `word.status_*`), `remint_offset` shift via `RemintRules`, undone reviews dropped, clock repair, then rebuild.
- **Preconditions** (§10.4): no `pending` rows, last response showed `|server_time - pt| <= 5 min`, guards G1/G2 pass after repair; otherwise the action is unavailable with reason 'fix your device clock, then sync'.
- **Discard list (MUST):** `RemintPreview` returns the count and the full list (per op, grouped under window parent, `D` ops included) of rejected ops Re-mint will delete without minting (`C`, `D`, `U` minus `E` and `R`, plus reviews of `R` dropped because undone). Re-mint refuses to run without a `RemintPreview` handle the caller obtained after the last change (so the UI cannot confirm blindly); Discard/Retry per op remain available.
- Clock repair as defined: `hlc_last` = greatest of `hlc_acked` and the hlc of every kept pending_op row; delete `remint_offset` when no clock-rejected row remains.
- No silent loss: every rejected row ends as re-minted, retried, user-discarded, or still listed.

## Carried in from T303a/C-10 review (must do here)
- DATA-LOSS HAZARD: `OpMinter.mintAll(…, at)` returns `MintResult.Refused` (does not throw). Inside a joined outer transaction, a Re-mint that discards rows then gets Refused (clock still blocked, G1/G2, rebuild_pending) would commit the discards with nothing re-minted. The Re-mint caller MUST throw on Refused so the whole tx rolls back. Acceptance test: Re-mint with clock_blocked set leaves every rejected row intact.
