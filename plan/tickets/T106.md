## Read
- Spec: Public API and scripting (Dictionary row); Data model › Reference data (docs/SPEC.md)
- Contracts: contracts/api/openapi.yaml `/dict/search` (interpretation order; retired entries excluded; order exact, prefix, rest, then `freq_rank` NULLS LAST, then `seq`; empty `q` is 422; `status`/`note_id` overlay), `/dict/entries/{seq}`, `/dict/entries/{seq}/examples`, `/kanji/{literal}` and their schemas; contracts/db/SCHEMA.md §4.5 "Search recipes (server)"; V1__init.sql `ref.*` indexes
- Fixtures: fixtures/dict/ (loaded through the T101 loader); the 50-query file is yours to author
- Decisions: docs/DECISIONS.md ADR-002 (shared logic lives in core; see the romaji note below)

## Do
- `/dict/search` for kanji, kana, romaji, English glosses and deinflected input, per the OpenAPI text. Romaji to kana: the OpenAPI says "the core's romaji-to-kana conversion", but core has no such function and no ticket covers it. Use a core function if one exists when you start; otherwise write a small table-driven converter under `kotobaya/dict/` and flag in HANDOFF that it should move to core (do not touch `core/`).
- Deinflection: a small ending-rule table for verbs and adjectives is enough to produce extra candidate dictionary forms (the full deinflector belongs to the later parser ticket).
- `/dict/entries/{seq}` and `/kanji/{literal}`; `/dict/entries/{seq}/examples` only if T102's tables are populated, otherwise leave it 501 and say so. The `status`/`note_id` overlay returns spec-default empty values when no learning rows exist.
- Author `server/src/test/resources/dict/queries.json`: 50 queries with the expected top `seq` on the fixture subset. Cover kana, kanji, romaji, English, a deinflected verb, a 1-character prefix, and a retired entry that must not appear.

## Acceptance
- [ ] The 50 fixture queries return the expected top result (one parameterised test).
- [ ] Retired entries never returned; empty `q` gives 422; paging works.
- [ ] The test database uses C.UTF-8 (V1 aborts otherwise, FOLLOWUPS) and is loaded with the T101 fixture; state in HANDOFF how (committed small SQL dump produced by the worker loader, or loader run in setup).
- [ ] `make check MODULE=server` green.

## Out of scope
Loading dictionary data (T101/T102); device packaging (T103); `/dict/release` and `/dict/refresh` (T109a and the dict-refresh job ticket); the full deinflector/parser (later worker ticket).
