- Decisions: ADR-011 (default card kinds), ADR-006 (deckless mined cards)

## Do
- Implement actions `deckNames`, `modelNames`, `modelFieldNames`, `canAddNotes`, `addNote`, `findNotes`,
  `storeMediaFile` exactly per the contract table; errors via `AnkiConnectError` (always HTTP 200 envelope).
- `addNote`: resolve model, match the dictionary entry with the core matcher (vocab base type), emit
  `note.created` (origin `ankiconnect`), `card.created` per default kind, and `deck.item_put` for a live user
  deck, all in one `OpApply` transaction (CLAUDE.md rule 8; reuse the `POST /notes` creation path from
  `notes/` by calling it, not copying it — if it is not callable, ask in HANDOFF).
- Duplicate rule and `allowDuplicate` exactly as specified (never a second note for the same entry).
- `anki_id`: derived from the UUIDv7 (48-bit ms x 32 + 5 bits); lookup picks smallest live id.
- `storeMediaFile`: base64 `data` or `url` -> blob; rewrite `[sound:name]` / `<img src=name>` in later `addNote`.
