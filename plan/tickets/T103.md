# T103 — Dictionary release packaging for devices

- Phase: P1 · Model: sonnet · Risk: med
- Deps: T102
- Branch: t/T103-dict-package
- Owned paths (only edit these): `worker/src/kotobaya_worker/dict/package/`, `worker/tests/dict/package/`
- Module(s) for CI: worker

## Read
- Spec: Sync and offline (large content: versioned compressed snapshots and diffs); Android app (dictionary scope, storage budget) (docs/SPEC.md)
- Contracts: contracts/db/SCHEMA.md §5.4 (dictionary file: separate SQLite conforming to `Dict.sq`, `PRAGMA user_version = 1`, subset allowed, child rows only for present entries) and §4.5; contracts/db/sqldelight/ref/ (`Dict.sq`); contracts/api/openapi.yaml `/dict/release` (`DictRelease`: the manifest the client reads) and the blob endpoints (content-addressed by hash); contracts/api/SUMMARY.md "Known gaps" (snapshot archive formats are undefined; this ticket defines the dictionary one)
- Decisions: docs/DECISIONS.md (phone dictionary scope default "referenced + top 60k", size budget 150 MB; ADR-003 S3 names)

## Do
- Build the compact SQLite file with exactly the `Dict.sq` schema for a scope: "referenced + top N" (referenced = entry seqs given by the caller) or full. zstd-compress. Upload content-addressed (`sha256`) via `S3_ENDPOINT`/`S3_BUCKET`/`S3_ACCESS_KEY`/`S3_SECRET_KEY`, creating the bucket if absent (FOLLOWUPS: app must create `S3_BUCKET`; SeaweedFS dev has no auth).
- Manifest with release version and a diff from the previous release (added/changed/retired entry rows) in a documented, versioned format. Describe the format in the module docstring and HANDOFF; the contract leaves it open, so flag it for the architect.
- A diff-apply function (used by tests; the Android side implements its own later).

## Acceptance
- [ ] Top-60k package is under the DECISIONS budget (150 MB unless changed). A test asserts the budget on a scaled synthetic release; the real number goes in HANDOFF.
- [ ] Applying the diff from fixture release A to A's package yields a database equal, table by table, to a fresh package of release B.
- [ ] Output opens read-only in sqlite3 with `user_version = 1` and has no dangling child rows.
- [ ] `make check MODULE=worker` green.

## Out of scope
Serving the manifest/blob endpoints (later server ticket; T106 is search only); the Android download client (P3); loading JMdict (T101/T102).
