## Do
Additive, non-breaking. Add operation `listKanjiWords`: `GET /kanji/{literal}/words`, tag `dictionary`,
scope `read`. Same `literal` rules as `getKanji` (one code point, `422` otherwise). A kanji absent from
`ref.kanji` is **not** a 404 here (entry_kanji.literal need not exist in ref.kanji) — just an empty page.

Query params:
- `deck_id` (optional uuid): only entries that are live items (`deleted_at IS NULL`) of that deck; unknown/not-yours deck → 404.
- `mine` (optional bool, default false): only entries in at least one of the caller's decks or with a live vocab note.
- `limit` (default 50, max 200), `cursor` (opaque).

Order: `deck_id` given → `occurrence_count` desc (in-deck frequency), then `freq_rank` asc nulls last, then `seq`.
Otherwise → `freq_rank` asc nulls last, then `seq`. Exclude retired entries.

Response `KanjiWordPage { items: KanjiWord[], next_cursor }` where `KanjiWord` = all `DictEntrySummary`
fields (allOf) plus `decks: [{deck_id, name, type, occurrence_count}]` — the caller's non-deleted decks
that hold this entry as a live item, ordered by name. Add an example. Regenerate clients
(`make check MODULE=contracts`).
