## Do

- Generate Kotlin (for android), TypeScript (for web) and Python (for CLI and worker) clients from `contracts/api/openapi.yaml` into `clients/kotlin`, `clients/typescript`, `clients/python`. Pin generator versions (openapi-generator-cli or per-language tools); pin the Docker image or npm/pip version; document the one command in `clients/README.md`. Never hand-edit generated files; mark them generated.
- Generated clients must compile: Kotlin via the existing Gradle setup if one can be added without touching other modules (otherwise a standalone `clients/kotlin` Gradle build invoked by the target), TypeScript with `tsc --noEmit`, Python with `python -m compileall` plus mypy if the generator emits types.
- The sync op JSON Schemas are NOT part of the API clients; leave them to T202/T303.
- Do not wire the clients into web, android or worker; those tickets consume them.
- If a contract check script needs a tool that is absent on the machine (docker), make the target print `SKIPPED: <tool>` for that one script and exit 0 only when the existing scripts already do so; do not silently skip the drift check.
