- **HTML / URL**: stdlib readability heuristic (prefer `<article>`/`<main>`, else the densest text block; drop nav/script/style/aside), ruby handled as in EPUB, one segment. URL fetch with timeout, size cap, http/https only, no redirects to other schemes; fetching is injectable for tests. No new dependency (if a readability library is truly needed, state why in HANDOFF; provisional default is stdlib).
