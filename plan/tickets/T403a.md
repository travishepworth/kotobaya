## Do
- `normalize.py`: width folding (full-width ASCII/digits, half-width katakana), iteration marks and odoriji expansion (々 kept as in JMdict keys; ゝゞヽヾ expanded), long-vowel/wave dash variants; returns normalised text **plus an offset map** back to original UTF-16 offsets, so tokens always point into the original text.
- `sudachi/`: SudachiPy with the **full** dictionary, mode C; for each C token whose lemma (and surface) is not a JMdict key, re-split with mode B (then A as last resort) — the JMdict check is an injected predicate so this ticket stays independent of ref.* matching (T403b). Tokenizer created once per process (expensive), thread-safe use documented.
- `deinflect/`: dictionary form + reading (katakana→hiragana) for verbs/adjectives from Sudachi's dictionary form and conjugation info, with a small rule table for cases Sudachi gets wrong against JMdict (e.g. する-verbs, い-adjective stems, colloquial contractions); auxiliary chains stay separate tokens (fixture convention).
- `segment.py`: `segment(sentence_text) -> list[RawToken(s, e, surface, lemma, reading, pos, cform)]`, punctuation/whitespace not emitted as tokens.
- Dependencies: `sudachipy` + `sudachidict_full` (pin versions; line in HANDOFF saying why). **Offline fallback:** if `sudachidict_full` cannot be downloaded in the sandbox, use `sudachidict_core` for development; the agreement test is parametrised by installed dictionary and gated `@pytest.mark.full_dict` for the ≥ 97 % threshold (skipped with a clear reason when full is absent), with a recorded core-dict baseline that must not regress.
