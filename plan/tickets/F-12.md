Reported by the human on the live cluster: when a dictionary refresh job is resumed (re-claimed after
a crash/restart or retried after a partial run), it completes the ref.* load but does NOT build/publish
the offline device package (DICT_PACKAGE), so phones never get the new release. Find the resume path
that skips the package step and make the job's steps idempotent and resumable so a resumed run always
ends with the package built and published (skip only steps whose outputs are verified present).
