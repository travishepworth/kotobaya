## Read
- Spec: Public API and scripting › Card search language; Data model (docs/SPEC.md)
- Contracts: core/src/commonMain/kotlin/kotobaya/contracts/search/Search.kt (AST node types and their documented meaning); contracts/core/search.ebnf and search-examples.tsv; contracts/db/V1__init.sql (server) and contracts/db/sqldelight/app/ (device) for the tables and columns a card search touches (`card`, `note`, `note.search_text`, `deck_item`/membership, `word_status`, `review_log`, tags, `fsrs` cache columns; follow SCHEMA.md §4.5 "Notes: `note.search_text`" and merged-note handling via `merged_into_id`, SCHEMA/SYNC §8.5)
- Gap: the frozen core contract defines no SQL-compiler interface (only the AST). Define a small public `SearchSqlCompiler` in `kotobaya.search.sql` returning parameterised SQL plus bind values for a `Dialect` (POSTGRES, SQLITE), and record it in HANDOFF as a contract addition for the architect (not a CONTRACT_CHANGE_REQUEST blocker, since nothing frozen depends on it).

## Do
- Compile every AST node to a `WHERE` fragment with bind parameters only (no string-interpolated user text), for both dialects. Differences to cover: `ILIKE` vs `LIKE ... COLLATE NOCASE`/`lower()`, boolean and timestamp types (epoch millis on device), trigram use on Postgres, array/JSON predicates.
- Exclude merged losers and deleted rows from results, as the schema contracts require.
- Keep it pure and common-code (no JDBC).

## Acceptance (each bullet → at least one named test)
- [ ] Every `+` example of `search-examples.tsv` compiles in both dialects; SQL text is snapshot-tested.
- [ ] Execution test on the jvm target: run the compiled SQL for a set of representative queries against SQLite loaded from `contracts/db/sqldelight` (if a JVM SQLite driver is already in the build) and compare result sets to an in-memory evaluation; if none is available, state it in HANDOFF and snapshot-test only. No new dependency without a line in HANDOFF.
- [ ] Injection-shaped inputs (quotes, `%`, `;`) never reach the SQL text.
- [ ] `make check MODULE=core` green.

## Out of scope
