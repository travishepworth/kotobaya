## Context (ci-triage, 2026-11-13)
`make check MODULE=server` dies with java.lang.OutOfMemoryError: Java heap space in "Gradle Test Executor 1"
(no test failure). The test worker uses Gradle's default heap (~512m); `-Xmx3g` in gradle.properties only
sizes the daemon. Each AuthFixture app builds AppDeps, which re-parses openapi.yaml via `ApiSpec.load()`
(Spec.kt:70, called from App.kt:32), uncached, so heap climbs across the run.

## Do
1. `tasks.test { maxHeapSize = "2g" }` (server/build.gradle.kts ~:57). Keep forks at 1 unless needed.
2. Cache the parsed spec (load once per JVM, e.g. a lazy val), since it is immutable. No behaviour change.
