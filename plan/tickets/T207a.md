## Do
- A pure, streaming-friendly function `plan_import(export_json, ref_lookup, options) -> ImportPlan`: map vocab by vid to `entry_seq` (verify the seq exists in `ref.dict_entry`; spelling/reading fallback only as S02 documents), merge rows repeating a vid onto one note/card by entry_seq, interleave events by timestamp, drop exact duplicates (same timestamp + grade), compute deterministic review ids (hash of vid, timestamp, grade, occurrence index; define the exact hash in one documented function and give a golden test), apply the C-4 grade table, `known`-only handling, kanji rows (both arrays share a note; `keyword` from the export if present, else empty), suspended flags for `writing` and known-only kanji.
- `ImportPlan` is a JSON-serialisable structure the server job (T207b) turns into ops (notes, cards, reviews, word statuses) plus the `JobResultJpdbHistory` counters and the `unmapped` / `kanji_unmapped` lists. Define it in one module and document it (HANDOFF carries the schema for T207b).
- Register the `jpdb-history-import` handler in the worker runner registry via a small adapter in this package (the W-1-style registry wiring line is flagged in HANDOFF; do not edit `runner/`).
- Tolerate missing arrays, unknown members, unknown grades (counted), `from_anki` true/absent.
