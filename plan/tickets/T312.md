## Do

- Workflow on tag `v*`: decode keystore from a secret, build BOTH flavors' release APKs, publish a GitHub release with assets `kotobaya-<version>.apk` (the **`ankidroid`/`com.ichi2.anki` default**) and `kotobaya-own-id-<version>.apk`; versionName from the tag, versionCode from the run number. Release notes list which APK to install and the AnkiDroid-conflict warning.
- `android/signing/README.md`: how to generate the keystore (`keytool` command), which secrets to set, Obtainium setup (add the repo URL, APK filter regex for the default asset), what to do if the signing key is lost.
