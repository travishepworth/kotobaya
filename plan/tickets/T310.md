- Follow-ups folded in: none

## Do
- `PrefetchPlanner` (pure): given due and soon-due cards (next N days, N a setting, default 2), their audio blob hashes, current `blob_cache`, the storage budget (setting, e.g. 500 MB) and sizes, returns which blobs to want and which to evict (LRU by last use, never evict blobs needed by cards due in the window, never exceed the budget).
- `AudioPrefetchWorker` (WorkManager, unmetered-network constraint by default, setting to allow metered): downloads wanted blobs with resume, verifies SHA-256, atomic rename into app-private storage by hash, updates `blob_cache`; 404 -> `missing`; respects budget; runs after sync.
- Storage breakdown for Settings > Offline storage (card audio, media, covers, dictionary from T302) via `blob_cache.reason`; 'clear cache' action; LRU touch when audio is played (T304b reads `blob_cache`).
- Koin module + registration line in `di/FeatureModules.kt` (flag in HANDOFF).

## Acceptance
- [ ] Planner tests: window selection by N days, budget respected, LRU eviction order, protected blobs never evicted, over-budget single blob skipped with a reason.
- [ ] Worker tests with a fake server: hash mismatch retried then marked failed, resume after partial, 404 -> `missing`, no download on a metered network by default.
- [ ] `make check MODULE=android` green.
