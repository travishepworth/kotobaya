# ReviewButton

Button pressed. Five-button mode uses `nothing`, `something` (both rating 1), `hard`, `okay` (rating 3), `easy`.

## Enum

* `AGAIN` (value: `'again'`)

* `HARD` (value: `'hard'`)

* `GOOD` (value: `'good'`)

* `EASY` (value: `'easy'`)

* `NOTHING` (value: `'nothing'`)

* `SOMETHING` (value: `'something'`)

* `OKAY` (value: `'okay'`)
